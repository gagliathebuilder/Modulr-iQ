# Launch ideas

This is a working backlog, not an approved launch plan.

## Narrative to test

Lead with the category and problem before product mechanics:

1. Buying systems changed. Supply descriptions did not.
2. Modulr makes publisher media machine-readable and agent-ready.
3. Evidence-backed supply intelligence reduces guesswork before execution.
4. Modulr remains publisher-aligned, execution-neutral, and protocol-agnostic.

## Launch surfaces

- Homepage: category clarity and pilot conversion
- Learn: durable search demand and reference-quality definitions
- Signal Shift: point of view, social distribution, and market timing
- LinkedIn: visual excerpts that link into Learn or Signal Shift—not generic company updates
- Pilot page: publisher-specific proof, expectations, qualification, and next step

## First experiments

- Test `Modulr` against `Modulr IQ` in social cards and outbound subject lines before changing the company identity.
- Publish one canonical “What is supply intelligence?” page designed to earn citations from search engines and AI answer systems.
- Give each Signal Shift issue one strong claim, one diagram, and one direct path into a relevant Learn module.
- Create publisher and platform entry pages with distinct questions and proof requirements.
- Replace email-only calls to action with the existing pilot funnel when the concept moves into production.

## Proof needed before public launch

- A real descriptor example with sensitive details removed
- One publisher workflow shown end to end
- Clear explanation of evidence, provenance, versioning, and neutrality
- Named pilot design or transparent “early access” expectations
- Search and AI-citation tracking connected to inquiry outcomes

## Decisions to record

- Company brand: Modulr, Modulr IQ, or Modulr with IQ as a product/system name
- Primary audience for launch: publishers, platforms, or both
- Public proof level available at launch
- Which repository owns visual identity and messaging canon
- Whether the preview replaces the existing site or informs a production redesign

## Homepage architecture decision — V4

The homepage hero now uses a system map as the primary product explanation. It separates four roles that should not be collapsed:

1. Seller Agent represents publisher-owned supply and context.
2. Modulr IQ resolves and governs supply intelligence.
3. Protocols transport that intelligence; they are not the product.
4. Buyer and activation systems discover, decide, transact, deliver, and return outcomes.

This remains a launch concept. It does not alter the existing production website.
