# Modulr IQ

Concept and launch workspace for the next Modulr website.

Modulr is the supply intelligence layer for agentic advertising. The site explores how to communicate that category clearly, build organic discoverability through Learn and Signal Shift, and convert publisher and platform interest into pilot conversations.

## Current direction

Version 3 meets between two earlier visual directions:

- V1: editorial clarity and conversion structure
- V2: provocative AI/AdTech manifesto energy
- V3: quiet product precision with enough category edge to remain distinctive

“Modulr IQ” remains an identity exploration, not a finalized rebrand.

## Site surfaces

- `/` — positioning, product system, audiences, and pilot conversion
- `/learn` — searchable AI-native advertising knowledge base
- `/signal-shift` — editorial series and category narrative

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Working approach

Use issues for ideas, launch experiments, content gaps, and decisions. Keep each visual milestone in Git so directions can be compared or restored without overwriting earlier thinking.
